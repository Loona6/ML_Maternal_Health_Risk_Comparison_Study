# Maternal Health Risk Prediction

A modular machine learning project to evaluate the robustness of models under various data degradation scenarios (MCAR, MNAR stock-outs, sensor drift, calibration errors).

## Directory Structure

- `data/raw/`: Raw datasets.
- `src/`: Core Python modules for modeling and evaluation.
- `notebooks/`: Jupyter notebooks for experiments and EDA.
- `results/`: Figures, tables, and raw CSV results.
